# 🌍 Flags Guessing Game

A simple and educational Python game built with the Turtle graphics library. The game displays a randomly selected national flag, and the player must guess which country it belongs to. Correct answers earn points, while incorrect answers reduce the player's lives. The game continues until all flags are guessed or the player runs out of lives.

This project was created as a fun way to practice Python programming, Turtle graphics, functions, loops, and basic game logic.

---

## 🎮 Features

- Draws multiple national flags using Python Turtle graphics.
- Random flag selection each round.
- Score tracking system.
- Life system (3 lives by default).
- Prevents the same flag from appearing twice after a correct guess.
- Educational gameplay that helps players learn world flags.
- Simple and beginner-friendly Python code.
